Step 03 · Exact release

Check out the exact release

For a clean checkout whose current release is an ancestor of the target:

export SOURCE_ROOT=/var/www/clients/client0/web6/web/gameday/source
export CACHE_ROOT=/var/www/clients/client0/web6/web/gameday/.cache
export TARGET_COMMIT=d36325c948a5f8c44895b6aa30c7dd2c82621eba

cd "$SOURCE_ROOT"
export OLD_COMMIT="$(git rev-parse HEAD)"

git merge-base --is-ancestor "$OLD_COMMIT" "$TARGET_COMMIT"
Check the command result before continuing.If that command fails, stop and reconcile the release branches. If it succeeds, review the complete update:
git diff --stat "$OLD_COMMIT" "$TARGET_COMMIT"
git diff --name-only "$OLD_COMMIT" "$TARGET_COMMIT" -- apps/api/drizzle

After reviewing the update and completing backups:

git checkout --detach "$TARGET_COMMIT"
git rev-parse HEAD

The output must match the full target commit above.

Step 04 · Compilation & database

Install, build, and migrate

Run installs and builds as web6, using the existing writable cache. Correct any root-owned build directories before proceeding.

run_app() {
  sudo -u web6 -H env \
    CI=true \
    XDG_CACHE_HOME="$CACHE_ROOT" \
    COREPACK_HOME="$CACHE_ROOT/corepack" \
    PNPM_HOME="$CACHE_ROOT/pnpm" \
    "$@"
}

run_app pnpm install --frozen-lockfile
run_app pnpm --filter api exec jest gameday-rules.spec.ts broadcast-feed.spec.ts --runInBand

run_app pnpm --filter api build
run_app pnpm --filter teams build
run_app pnpm --filter platform build
Execute each command separately and stop on any failure.
