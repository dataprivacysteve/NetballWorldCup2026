Approval-card spacing fix

Installation and rollback guide for the responsive registration-details layout correction.

Package scope

This package changes only apps/platform/app/page.tsx. It prevents contact email and phone values from overlapping, adds responsive columns and permits long values to wrap. It contains no database migration, credentials or environment file.

Step 1

Set deployment variables

export SITE_USER=web6
export SITE_GROUP=client0
export SOURCE_ROOT=/var/www/clients/client0/web6/web/gameday/source
export CACHE_ROOT=/var/www/clients/client0/web6/web/gameday/.cache
export PACKAGE=/tmp/platform-spacing-fix.zip

test -f "$SOURCE_ROOT/apps/platform/app/page.tsx" || { echo "Wrong source path"; exit 1; }
Step 2

Back up and install

cp "$SOURCE_ROOT/apps/platform/app/page.tsx" \
  "$SOURCE_ROOT/apps/platform/app/page.tsx.before-spacing-fix"

export WORK_DIR="$(mktemp -d /tmp/platform-spacing.XXXXXX)"
unzip -q "$PACKAGE" -d "$WORK_DIR"
test -f "$WORK_DIR/platform-spacing-fix/apps/platform/app/page.tsx" \
  || { echo "Invalid package"; exit 1; }

cp "$WORK_DIR/platform-spacing-fix/apps/platform/app/page.tsx" \
  "$SOURCE_ROOT/apps/platform/app/page.tsx"
chown "$SITE_USER:$SITE_GROUP" "$SOURCE_ROOT/apps/platform/app/page.tsx"
Step 3

Build as the ISPConfig site user

test ! -d "$SOURCE_ROOT/apps/platform/.next" || \
  chown -R "$SITE_USER:$SITE_GROUP" "$SOURCE_ROOT/apps/platform/.next"

cd "$SOURCE_ROOT"
sudo -u "$SITE_USER" -H env \
  XDG_CACHE_HOME="$CACHE_ROOT" \
  COREPACK_HOME="$CACHE_ROOT/corepack" \
  PNPM_HOME="$CACHE_ROOT/pnpm" \
  pnpm --filter platform build
Stop if the build fails. Do not restart the currently working Platform service with an incomplete build.
Step 4

Restart and verify

supervisorctl restart gameday-platform
sleep 8
supervisorctl status gameday-platform
ss -lntp | grep ':3003'
tail -n 40 /var/log/gameday/platform-error.log
Expected: gameday-platform RUNNING. Hard-refresh the browser, open Registrations and verify that email and phone no longer overlap at desktop and tablet widths.
Rollback

Restore the previous page

cp "$SOURCE_ROOT/apps/platform/app/page.tsx.before-spacing-fix" \
  "$SOURCE_ROOT/apps/platform/app/page.tsx"
chown "$SITE_USER:$SITE_GROUP" "$SOURCE_ROOT/apps/platform/app/page.tsx"

cd "$SOURCE_ROOT"
sudo -u "$SITE_USER" -H env \
  XDG_CACHE_HOME="$CACHE_ROOT" COREPACK_HOME="$CACHE_ROOT/corepack" PNPM_HOME="$CACHE_ROOT/pnpm" \
  pnpm --filter platform build
supervisorctl restart gameday-platform
sleep 8
supervisorctl status gameday-platform
