Read this before opening the terminal

This runbook intentionally stops unless the live server is already at the expected application and database baseline. Do not improvise around a failed check.

Absolute stop rule If a command prints STOP, if its output differs from the stated expected result, or if you are unsure what a value means: stop typing, keep the services in their current state, copy the non-sensitive output, and contact the lead developer. Do not “try something” on production.

Step 8 · Data integrity evidence

Capture privacy-safe row counts and fingerprints

These queries hash identifiers and statuses, not names, emails, dates of birth or document contents.

psql "$MIGRATION_DATABASE_URL" -X -v ON_ERROR_STOP=1 -A -F '|' \
  -c "SELECT 'delegation', COUNT(*), md5(COALESCE(string_agg(id::text || ':' || registration_status::text || ':' || status::text, '|' ORDER BY id),'')) FROM delegation
      UNION ALL
      SELECT 'player', COUNT(*), md5(COALESCE(string_agg(id::text || ':' || delegation_id::text || ':' || category::text, '|' ORDER BY id),'')) FROM player
      UNION ALL
      SELECT 'identity_document', COUNT(*), md5(COALESCE(string_agg(id::text || ':' || player_id::text || ':' || status::text || ':' || COALESCE(object_key,'NO_FILE'), '|' ORDER BY id),'')) FROM identity_document
      UNION ALL
      SELECT 'credential', COUNT(*), md5(COALESCE(string_agg(id::text || ':' || player_id::text || ':' || status::text, '|' ORDER BY id),'')) FROM credential
      ORDER BY 1" \
  > "$EVIDENCE_ROOT/core-records-before.txt"

cat "$EVIDENCE_ROOT/core-records-before.txt"

psql "$MIGRATION_DATABASE_URL" -X -Atc \
  "SELECT COUNT(*) FROM identity_document WHERE object_key IS NOT NULL" \
  > "$EVIDENCE_ROOT/identity-files-before.txt"
ExpectedThe file contains four labelled rows and the identity-file count contains one integer. If a query fails, do not migrate.

Audit-trail check

If failure occurs after migration 0041

Migration 0041 is additive. Leave the unused enum value in PostgreSQL and roll back the application code as above. Do not attempt to remove the enum value. Do not restore the database dump merely to remove migration 0041.

If the Federation account was already createdKeep the applications stopped and have the lead developer disable that account before starting the old release. Do not improvise a database update. Record the action and tell the Federation reviewer that access is suspended.

If any protected-record fingerprint changed

Senior incident procedureKeep applications stopped, preserve logs and evidence, and contact the lead developer plus database owner. A database restore requires explicit approval and a review of all writes since the backup; an unplanned restore could delete new registrations.
