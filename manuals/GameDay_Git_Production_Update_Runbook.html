GameDay Git Production Update Runbook

The repeatable process for safely moving verified GameDay changes from the Windows development workspace into the Debian 13, ISPConfig-managed production environment.

GitHubDebian 13ISPConfigSupervisorNode.js 22pnpm monorepo

Operating rule

Git is the standard deployment channel. ZIP packages are reserved for bounded emergency hotfixes. Production secrets, uploads, logs, database dumps and server-generated files never enter Git.
1. Verify locally2. Open maintenance window3. Back up4. Pull release5. Correct ownership6. Install dependencies7. Migration gate8. Build9. Restart10. Smoke test11. Record releaseRollback
1
Development workstation

Prepare and verify locally

Review the worktree and ensure only intentional changes enter the release.

git status --short
git diff

Run the application builds and focused tests:

pnpm --filter api build
pnpm --filter teams build
pnpm --filter platform build
pnpm --filter api exec jest roster-rules.spec.ts --runInBand

Stage only intended source and dependency files:

git add apps/api
git add apps/teams
git add apps/platform
git add package.json pnpm-lock.yaml .env.example

git diff --cached --stat
git diff --cached
Stop conditionDo not commit .env, credentials, private documents, exports, logs, backups, uploaded identity evidence or unrelated worktree changes.

Commit and push the reviewed release:

git commit -m "Add rolling LOC roster review and production fixes"
git push origin main
2
Production server

Begin a short maintenance window

export SITE_USER=web6
export SITE_GROUP=client0
export SOURCE_ROOT=/var/www/clients/client0/web6/web/gameday/source
export CACHE_ROOT=/var/www/clients/client0/web6/web/gameday/.cache

cd "$SOURCE_ROOT"
git status --short
git branch --show-current
git remote -v
Stop conditionIf production contains unexpected modifications, do not pull. Preserve and reconcile them first. Never use git reset --hard as a routine deployment shortcut.
3
Recovery gate

Back up the active release

export BACKUP_ROOT=/var/www/clients/client0/web6/web/gameday/backups
export RELEASE_TIME="$(date +%Y%m%d-%H%M%S)"

install -d -o "$SITE_USER" -g "$SITE_GROUP" -m 0750 "$BACKUP_ROOT"
git rev-parse HEAD > "$BACKUP_ROOT/commit-before-$RELEASE_TIME.txt"

tar -C "$SOURCE_ROOT" \
  -czf "$BACKUP_ROOT/source-before-$RELEASE_TIME.tar.gz" \
  apps package.json pnpm-lock.yaml

When the release includes database migrations, create a verified database dump before migrating:

install -d -m 0700 /secure/backup
pg_dump -h 127.0.0.1 -U cogameday -Fc gameday \
  -f "/secure/backup/gameday-$RELEASE_TIME.dump"

test -s "/secure/backup/gameday-$RELEASE_TIME.dump" \
  && echo "Database backup created" \
  || { echo "Database backup failed"; exit 1; }
Current rolling-review updateNo database migration is required for the partial-roster workflow.
4
Release intake

Pull the approved commit

cd "$SOURCE_ROOT"
git fetch origin
git pull --ff-only origin main
git log -1 --oneline

Record the new commit shown by git log. A non-fast-forward result is a stop condition requiring investigation.

5
ISPConfig filesystem

Correct build ownership

Earlier root-run builds caused recurring EACCES failures. Dependencies and build outputs must be writable by web6:client0.

chown "$SITE_USER:$SITE_GROUP" "$SOURCE_ROOT"

find "$SOURCE_ROOT" -type d -name node_modules -prune \
  -exec chown -R "$SITE_USER:$SITE_GROUP" {} +

test ! -d "$SOURCE_ROOT/apps/api/dist" || \
  chown -R "$SITE_USER:$SITE_GROUP" "$SOURCE_ROOT/apps/api/dist"
test ! -d "$SOURCE_ROOT/apps/teams/.next" || \
  chown -R "$SITE_USER:$SITE_GROUP" "$SOURCE_ROOT/apps/teams/.next"
test ! -d "$SOURCE_ROOT/apps/platform/.next" || \
  chown -R "$SITE_USER:$SITE_GROUP" "$SOURCE_ROOT/apps/platform/.next"

install -d -o "$SITE_USER" -g "$SITE_GROUP" -m 0750 \
  "$CACHE_ROOT" "$CACHE_ROOT/corepack" "$CACHE_ROOT/pnpm"
Permanent practiceRun every pnpm install and build as web6, never as root. ISPConfig’s parent directory remains root-owned; the application cache stays under web/gameday/.cache.
6
Deterministic install

Install locked dependencies

cd "$SOURCE_ROOT"
sudo -u "$SITE_USER" -H env \
  CI=true \
  XDG_CACHE_HOME="$CACHE_ROOT" \
  COREPACK_HOME="$CACHE_ROOT/corepack" \
  PNPM_HOME="$CACHE_ROOT/pnpm" \
  pnpm install --frozen-lockfile
Stop conditionIf dependency installation fails, do not restart any working service. Correct ownership, network, cache or lockfile problems first.
7
Database change gate

Run migrations only when included

git diff HEAD^ --name-only | grep '^apps/api/drizzle/' \
  || echo "No database migrations"

If migration files are present and the backup passed:

sudo -u "$SITE_USER" -H env \
  XDG_CACHE_HOME="$CACHE_ROOT" \
  COREPACK_HOME="$CACHE_ROOT/corepack" \
  PNPM_HOME="$CACHE_ROOT/pnpm" \
  pnpm --filter api db:migrate

After role-related migrations, explicitly verify production capabilities such as the approved gameday_platform BYPASSRLS requirement.

8
Release compilation

Build affected applications

For an update affecting the API, Team Portal and LOC Platform:

sudo -u "$SITE_USER" -H env \
  XDG_CACHE_HOME="$CACHE_ROOT" COREPACK_HOME="$CACHE_ROOT/corepack" PNPM_HOME="$CACHE_ROOT/pnpm" \
  pnpm --filter api build

sudo -u "$SITE_USER" -H env \
  XDG_CACHE_HOME="$CACHE_ROOT" COREPACK_HOME="$CACHE_ROOT/corepack" PNPM_HOME="$CACHE_ROOT/pnpm" \
  pnpm --filter teams build

sudo -u "$SITE_USER" -H env \
  XDG_CACHE_HOME="$CACHE_ROOT" COREPACK_HOME="$CACHE_ROOT/corepack" PNPM_HOME="$CACHE_ROOT/pnpm" \
  pnpm --filter platform build
Stop conditionDo not restart services unless every required build completes successfully.

10
Acceptance gate

Perform production smoke tests

API availability

curl -sS -o /dev/null -w 'API HTTP %{http_code}\n' \
  https://api.netballamericas.org/registration-window

Expected response: API HTTP 200.

Functional checks

  1. Team and LOC sign-in both work; /me returns HTTP 200.
  2. A pending team registration appears for LOC approval.
  3. A team can add one person.
  4. The team can use Send current records for LOC review.
  5. The partial roster appears under LOC Roster review.
  6. The team can continue adding and updating people during preliminary review.
  7. Final accreditation submission remains disabled until the complete roster is ready.
  8. The LOC cannot approve an incomplete roster for accreditation.
  9. Country displays the selected country name, not the team name.
  10. Password-reset email reaches the requesting account.
  11. New-registration notification reaches loc@netballamericas.org.
  12. LOC approval-card email and phone values do not overlap.

Logs

tail -n 100 /var/log/gameday/api-error.log
tail -n 100 /var/log/gameday/teams-error.log
tail -n 100 /var/log/gameday/platform-error.log
Release failureA service not running, API response other than 200, login regression, missing registration, cross-team visibility failure or broken critical workflow requires correction or rollback before closing the maintenance window.
11
Deployment evidence

Record the deployed version

cd "$SOURCE_ROOT"
git rev-parse HEAD
git log -1 --oneline
date --iso-8601=seconds

Record the commit hash, operator, deployment time, migration status, service status and smoke-test result. This creates a deterministic audit and rollback point.

Recovery procedure

Rollback the application release

Use the exact pre-release commit recorded in Step 3. Prefer a Git revert/new corrective commit for normal operations. During an urgent failed cutover, restore the timestamped application archive:

supervisorctl stop gameday-api gameday-teams gameday-platform

tar -xzf "$BACKUP_ROOT/source-before-$RELEASE_TIME.tar.gz" \
  -C "$SOURCE_ROOT"

find "$SOURCE_ROOT" -type d -name node_modules -prune \
  -exec chown -R "$SITE_USER:$SITE_GROUP" {} +

cd "$SOURCE_ROOT"
sudo -u "$SITE_USER" -H env \
  CI=true XDG_CACHE_HOME="$CACHE_ROOT" COREPACK_HOME="$CACHE_ROOT/corepack" PNPM_HOME="$CACHE_ROOT/pnpm" \
  pnpm install --frozen-lockfile

sudo -u "$SITE_USER" -H env XDG_CACHE_HOME="$CACHE_ROOT" COREPACK_HOME="$CACHE_ROOT/corepack" PNPM_HOME="$CACHE_ROOT/pnpm" pnpm --filter api build
sudo -u "$SITE_USER" -H env XDG_CACHE_HOME="$CACHE_ROOT" COREPACK_HOME="$CACHE_ROOT/corepack" PNPM_HOME="$CACHE_ROOT/pnpm" pnpm --filter teams build
sudo -u "$SITE_USER" -H env XDG_CACHE_HOME="$CACHE_ROOT" COREPACK_HOME="$CACHE_ROOT/corepack" PNPM_HOME="$CACHE_ROOT/pnpm" pnpm --filter platform build

supervisorctl start gameday-api gameday-teams gameday-platform
sleep 8
supervisorctl status gameday-api gameday-teams gameday-platform
Database warningApplication rollback does not automatically reverse database migrations. Restore or reverse a database migration only through a migration-specific, reviewed recovery plan.
