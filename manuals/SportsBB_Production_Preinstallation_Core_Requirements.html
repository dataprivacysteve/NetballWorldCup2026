Purpose

How to complete this document

Complete only the fields below and return the document to SportsBB before the agreed installation date.

Do not type passwords or private keys into this document. Record who will provide access and use an agreed secure channel for credentials. Email and ordinary messaging should not be used for server passwords, database passwords, API secrets or SSH private keys.
ScopeThis form gathers infrastructure information only. Tournament configuration, team registration policy, logos, website content and GameDay staffing are handled separately.

Core requirement 2

Live server

Minimum production baseline

  • Dedicated Linux server or virtual machine with a currently supported 64-bit distribution.
  • 4 vCPU, 8 GB RAM and 100 GB SSD storage available to GameDay.
  • Docker Engine and Docker Compose permitted.
  • Public static IPv4 address.
  • Inbound TCP ports 80 and 443 permitted; SSH restricted to authorised administrators.
  • Outbound HTTPS and transactional-email-provider access permitted.
  • Server clock synchronised by NTP; production timezone recorded below.

Handoff gate

Ready-to-install confirmation

  • Live Linux server meets the minimum baseline and is reachable by SSH.
  • SportsBB has approved, time-limited administrative access through a secure channel.
  • Production hostnames are confirmed and DNS changes are authorised.
  • Ports 80 and 443 are available for HTTPS.
  • Transactional email provider and sender identity are approved.
  • Encrypted off-server backup destination and owner are confirmed.
  • Named SportsBB administrator and single LOC officer are confirmed.
  • Installation window and acceptance owner are confirmed.
Installation must not beginif server access, DNS authority, HTTPS reachability, production secrets handoff or backup ownership is unresolved.
