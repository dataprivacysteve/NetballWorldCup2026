Step 1

Set and verify the confirmed environment

Run as root. Copy commands only—not prose labels.

export SITE_USER=web6
export SITE_GROUP=client0
export SOURCE_ROOT=/var/www/clients/client0/web6/web/gameday/source
export CACHE_ROOT=/var/www/clients/client0/web6/web/gameday/.cache
export BACKUP_ROOT=/var/backups/gameday

cd "$SOURCE_ROOT"
pwd
id "$SITE_USER"
git remote -v
git status --short
supervisorctl status gameday-api gameday-teams gameday-platform
ss -lntp | grep -E ':3000|:3002|:3003'
Stop if git status --short shows tracked server-side source edits. Record and review them before pulling. Do not run git reset --hard, git checkout -- ., or delete the working tree.
Step 2

Prove that main contains e98125c

cd "$SOURCE_ROOT"
git fetch --prune origin

git rev-parse origin/main
git merge-base --is-ancestor e98125c origin/main \
  && echo "PASS: e98125c is included in origin/main" \
  || { echo "STOP: PR #1 is not merged into main"; exit 1; }
Continue only after PASS. A merge commit may mean origin/main has a different/newer hash; the ancestry check is the authoritative proof that the release is included.
Step 3

Record the old release and back up PostgreSQL

cd "$SOURCE_ROOT"
export OLD_COMMIT="$(git rev-parse HEAD)"
echo "OLD_COMMIT=$OLD_COMMIT"
git log -1 --oneline

install -d -o root -g root -m 0700 "$BACKUP_ROOT"
export BACKUP_FILE="$BACKUP_ROOT/gameday-before-e98125c-$(date +%Y%m%d-%H%M%S).dump"

set -a
. "$SOURCE_ROOT/.env"
set +a

test -n "$MIGRATION_DATABASE_URL" \
  || { echo "STOP: MIGRATION_DATABASE_URL is not loaded"; exit 1; }

pg_dump "$MIGRATION_DATABASE_URL" -Fc -f "$BACKUP_FILE"
test -s "$BACKUP_FILE" \
  && echo "PASS: database backup created at $BACKUP_FILE" \
  || { echo "STOP: database backup failed"; exit 1; }
Do not continue without a non-empty backup. Do not paste database passwords into shell history or screenshots.
Step 4

Fast-forward production main

cd "$SOURCE_ROOT"
git switch main
git pull --ff-only origin main

export NEW_COMMIT="$(git rev-parse HEAD)"
echo "NEW_COMMIT=$NEW_COMMIT"
git log -1 --oneline

git merge-base --is-ancestor e98125c HEAD \
  && echo "PASS: Phase 1 release is present" \
  || { echo "STOP: e98125c is not in the checked-out release"; exit 1; }

test -f apps/api/drizzle/0029_biography_minimum_700.sql \
  && echo "PASS: migration 0029 is present" \
  || { echo "STOP: migration 0029 is missing"; exit 1; }
Step 5

Restore ISPConfig ownership and writable caches

Git was run as root, but builds must run as the ISPConfig site user.

chown -R "$SITE_USER:$SITE_GROUP" "$SOURCE_ROOT"

install -d -o "$SITE_USER" -g "$SITE_GROUP" -m 0750 \
  "$CACHE_ROOT" \
  "$CACHE_ROOT/corepack" \
  "$CACHE_ROOT/pnpm"

find "$SOURCE_ROOT" -type d -name node_modules -prune \
  -exec stat -c '%U:%G %n' {} \;

stat -c '%U:%G %a %n' \
  "$SOURCE_ROOT" "$CACHE_ROOT" "$CACHE_ROOT/corepack" "$CACHE_ROOT/pnpm"
Expected: source and dependency directories are web6:client0. Cache must remain under /var/www/clients/client0/web6/web/gameday/.cache; do not use /var/www/clients/client0/web6/.cache.
Step 6

Stop all three applications before replacing builds

supervisorctl stop gameday-api gameday-teams gameday-platform

sleep 3
supervisorctl status gameday-api gameday-teams gameday-platform
ss -lntp | grep -E ':3000|:3002|:3003' \
  && echo "STOP: one or more old listeners remain" \
  || echo "PASS: application ports are free"

If a listener remains, identify it before killing anything:

ss -lntp | grep -E ':3000|:3002|:3003'
ps -fp <PID_FROM_SS>
Do not paste explanatory prose into the shell. Replace <PID_FROM_SS> with the actual PID only after confirming it belongs to GameDay.
Step 7

Install locked dependencies and apply migration 0029

cd "$SOURCE_ROOT"

sudo -u "$SITE_USER" -H env \
  CI=true \
  XDG_CACHE_HOME="$CACHE_ROOT" \
  COREPACK_HOME="$CACHE_ROOT/corepack" \
  PNPM_HOME="$CACHE_ROOT/pnpm" \
  pnpm install --frozen-lockfile

sudo -u "$SITE_USER" -H env \
  XDG_CACHE_HOME="$CACHE_ROOT" \
  COREPACK_HOME="$CACHE_ROOT/corepack" \
  PNPM_HOME="$CACHE_ROOT/pnpm" \
  MIGRATION_DATABASE_URL="$MIGRATION_DATABASE_URL" \
  pnpm --filter api db:migrate
Migration effect: the tournament biography minimum becomes 700 characters. Existing biographies remain stored; profiles below the minimum display incomplete until corrected.

supervisorctl status gameday-api gameday-teams gameday-platform

Expected: all three Supervisor programs show RUNNING; ports 3000, 3002 and 3003 each have one listener; API returns tournament JSON including endsOn; both Next.js applications return an HTTP response.

Step 10

Production functional smoke test

  • Open https://teams.netballamericas.org; sign-in screen loads with official event branding.
  • Sign in to a test team; dashboard, Players & Officials and Submission Status load without “Failed to fetch”.
  • Confirm biography counter requires 700 characters.
  • Confirm Passport expiry calendar does not accept a date before the tournament end.
  • Confirm Approved, Returned and Pending filters are clickable in Team Portal.
  • Open https://platform.netballamericas.org; LOC login and dashboard load.
  • Confirm LOC Team Review shows full submitted person information and clickable status filters.
  • Confirm a current LOC-approved player appears in match-sheet selection and dropdown shows names only.
  • Confirm success messages appear after a safe test write action.
  • Confirm Data handling & privacy notice opens and closes.
Use synthetic test data only. Do not upload a real passport as a deployment smoke test.
Step 11

Rollback if a critical test fails

Database rollback is required if migration or post-migration writes make code-only rollback unsafe. Coordinate with the lead engineer before restoring the dump; restoring overwrites data created after the backup.

Code rollback before new production registrations

supervisorctl stop gameday-api gameday-teams gameday-platform
cd "$SOURCE_ROOT"
git switch --detach "$OLD_COMMIT"
chown -R "$SITE_USER:$SITE_GROUP" "$SOURCE_ROOT"

sudo -u "$SITE_USER" -H env CI=true \
  XDG_CACHE_HOME="$CACHE_ROOT" COREPACK_HOME="$CACHE_ROOT/corepack" \
  PNPM_HOME="$CACHE_ROOT/pnpm" pnpm install --frozen-lockfile

sudo -u "$SITE_USER" -H env XDG_CACHE_HOME="$CACHE_ROOT" COREPACK_HOME="$CACHE_ROOT/corepack" PNPM_HOME="$CACHE_ROOT/pnpm" pnpm --filter api build
sudo -u "$SITE_USER" -H env XDG_CACHE_HOME="$CACHE_ROOT" COREPACK_HOME="$CACHE_ROOT/corepack" PNPM_HOME="$CACHE_ROOT/pnpm" pnpm --filter teams build
sudo -u "$SITE_USER" -H env XDG_CACHE_HOME="$CACHE_ROOT" COREPACK_HOME="$CACHE_ROOT/corepack" PNPM_HOME="$CACHE_ROOT/pnpm" pnpm --filter platform build

supervisorctl start gameday-api gameday-teams gameday-platform
sleep 10
supervisorctl status gameday-api gameday-teams gameday-platform

After recovery, return the repository to main only when engineering confirms the corrected release.
