GameDay Email Fix

Step-by-step installation guide for direct SMTP delivery, LOC registration notifications, password-reset email, and the team-country display correction.

Debian 13ISPConfigSupervisorNode.js 22 / pnpmPackage: emailfix.zip

Deployment sequence

  1. Pre-check and backup
  2. Install the files
  3. Configure SMTP
  4. Install, build and restart
  5. Test delivery
  6. Troubleshoot
  7. Rollback
Step 1

Pre-check and backup

Do not copy a development .env to production. The ZIP contains only .env.example. Production secrets stay in the server's protected environment file.

Run as root. Confirm the deployed source location and derive the real ISPConfig group instead of assuming that a group named web6 exists.

export SITE_USER=web6
export SITE_GROUP="$(id -gn "$SITE_USER")"
export SOURCE_ROOT=/var/www/clients/client0/web6/web/gameday/source
export CACHE_ROOT=/var/www/clients/client0/web6/web/gameday/.cache

test -d "$SOURCE_ROOT/apps/api" || { echo "Wrong SOURCE_ROOT"; exit 1; }
echo "User: $SITE_USER  Group: $SITE_GROUP"
supervisorctl status gameday-api gameday-teams

Create a timestamped code backup before overlaying the package:

export BACKUP_ROOT=/var/www/clients/client0/web6/web/gameday/backups
install -d -o "$SITE_USER" -g "$SITE_GROUP" -m 0750 "$BACKUP_ROOT"
tar -C "$SOURCE_ROOT" -czf "$BACKUP_ROOT/emailfix-before-$(date +%Y%m%d-%H%M%S).tar.gz" \
  apps/api apps/teams .env.example pnpm-lock.yaml
Step 2

Install the package files

Upload emailfix.zip to a temporary server location such as /tmp/emailfix.zip. The archive contains a top-level emailfix directory and preserves repository paths.

export PACKAGE=/tmp/emailfix.zip
export WORK_DIR="$(mktemp -d /tmp/gameday-emailfix.XXXXXX)"

unzip -q "$PACKAGE" -d "$WORK_DIR"
test -f "$WORK_DIR/emailfix/apps/api/src/mail/mail.service.ts" \
  || { echo "Package structure is invalid"; exit 1; }

cp -a "$WORK_DIR/emailfix/." "$SOURCE_ROOT/"
chown -R "$SITE_USER:$SITE_GROUP" \
  "$SOURCE_ROOT/apps/api" "$SOURCE_ROOT/apps/teams" \
  "$SOURCE_ROOT/pnpm-lock.yaml" "$SOURCE_ROOT/.env.example"
Expected code additions: apps/api/src/mail/mail.module.ts and mail.service.ts. The package also updates authentication, registration, delegation display, API dependencies and the lockfile.
Step 3

Configure production SMTP

Edit the production .env used by Supervisor. If $SOURCE_ROOT/.env is a symlink, edit its target. Do not place secrets in Git.

cd "$SOURCE_ROOT"
readlink -f .env
sudoedit "$(readlink -f .env)"

Add or update these values:

EMAIL_WEBHOOK_URL=

SMTP_HOST=mail.netballamericas.org
SMTP_PORT=25
SMTP_SECURE=false
SMTP_REQUIRE_TLS=false
SMTP_TLS_REJECT_UNAUTHORIZED=true
SMTP_FROM=GameDay <loc@netballamericas.org>

LOC_NOTIFICATION_EMAIL=loc@netballamericas.org

# Set these only if mail.netballamericas.org requires authentication.
SMTP_USER=
SMTP_PASSWORD=
Important: EMAIL_WEBHOOK_URL must be empty or removed. A non-empty webhook takes precedence over SMTP.
SettingMeaning
SMTP_FROMSender shown on outgoing mail. The mail server must permit it.
LOC_NOTIFICATION_EMAILRecipient for new delegation-registration alerts.
Password resetsAlways go to the email address of the account requesting the reset—not automatically to the LOC.

Protect and verify the environment file:

chown root:"$SITE_GROUP" "$(readlink -f .env)"
chmod 0640 "$(readlink -f .env)"
sudo -u "$SITE_USER" test -r .env \
  && echo "Environment readable" \
  || { echo "Environment NOT readable"; exit 1; }
Step 4

Install, build and restart

Use the ISPConfig-safe cache location. This prevents Corepack from trying to create /var/www/clients/client0/web6/.cache, which is owned by root.

install -d -o "$SITE_USER" -g "$SITE_GROUP" -m 0750 \
  "$CACHE_ROOT" "$CACHE_ROOT/corepack" "$CACHE_ROOT/pnpm"

cd "$SOURCE_ROOT"
sudo -u "$SITE_USER" -H env \
  XDG_CACHE_HOME="$CACHE_ROOT" \
  COREPACK_HOME="$CACHE_ROOT/corepack" \
  PNPM_HOME="$CACHE_ROOT/pnpm" \
  pnpm install --frozen-lockfile

sudo -u "$SITE_USER" -H env \
  XDG_CACHE_HOME="$CACHE_ROOT" \
  COREPACK_HOME="$CACHE_ROOT/corepack" \
  PNPM_HOME="$CACHE_ROOT/pnpm" \
  pnpm --filter api build

sudo -u "$SITE_USER" -H env \
  XDG_CACHE_HOME="$CACHE_ROOT" \
  COREPACK_HOME="$CACHE_ROOT/corepack" \
  PNPM_HOME="$CACHE_ROOT/pnpm" \
  pnpm --filter teams build

Restart and verify the two affected services:

supervisorctl restart gameday-api gameday-teams
sleep 8
supervisorctl status gameday-api gameday-teams
ss -lntp | grep -E ':3000|:3002'
tail -n 60 /var/log/gameday/api-error.log
Proceed only when both services show RUNNING.
Step 5

Verify the fix

A. Confirm the SMTP port is reachable

timeout 10 bash -c '</dev/tcp/mail.netballamericas.org/25' \
  && echo "SMTP port reachable" \
  || echo "SMTP port blocked or unreachable"

B. Test password recovery

  1. Open the portal's Forgot password screen.
  2. Enter a known test account email.
  3. Confirm the message reaches that account.
  4. Open the link and set a test password.
  5. Confirm the old password/session no longer works.

Watch the API log while testing:

tail -f /var/log/gameday/api-error.log

C. Test LOC registration notification

  1. Create one controlled test delegation using an unused eligible country.
  2. Confirm loc@netballamericas.org receives the “awaiting approval” message.
  3. Confirm the new registration still exists if email delivery fails; mail failure must appear in the API log.

D. Verify the country correction

  1. Sign in to the new test team account.
  2. Open Team registration.
  3. Confirm “Country” shows the selected country name, not the team name.
Troubleshooting

Common failures

SymptomLikely cause / action
Webhook error or example domain appearsEMAIL_WEBHOOK_URL is still non-empty. Clear it and restart the API.
ECONNREFUSED or timeoutDNS, firewall, outbound port 25, or mail service availability. Test TCP reachability from the production host.
Relay access deniedThe server does not permit anonymous relay. Obtain SMTP credentials or allow the production server IP.
Authentication failedCheck SMTP_USER/SMTP_PASSWORD and permitted sender address.
Certificate verification errorCorrect the mail server certificate. Do not permanently disable verification. A temporary diagnostic can set SMTP_TLS_REJECT_UNAUTHORIZED=false.
No registration email and no API errorConfirm LOC_NOTIFICATION_EMAIL is set and the new API build is running.
Old behaviour remainsRebuild both affected apps, restart both Supervisor processes, then hard-refresh the browser.

Safe configuration check without printing secrets:

cd "$SOURCE_ROOT"
grep -qE '^EMAIL_WEBHOOK_URL=$' .env && echo "Webhook disabled" || echo "Check webhook"
grep -qE '^SMTP_HOST=mail\.netballamericas\.org$' .env && echo "SMTP host set" || echo "SMTP host missing"
grep -qE '^LOC_NOTIFICATION_EMAIL=loc@netballamericas\.org$' .env && echo "LOC recipient set" || echo "LOC recipient missing"
Rollback

Restore the previous application files

Use the timestamped archive created in Step 1. Substitute the actual backup filename:

supervisorctl stop gameday-api gameday-teams
cd "$SOURCE_ROOT"
tar -xzf "$BACKUP_ROOT/emailfix-before-YYYYMMDD-HHMMSS.tar.gz" -C "$SOURCE_ROOT"
chown -R "$SITE_USER:$SITE_GROUP" "$SOURCE_ROOT/apps/api" "$SOURCE_ROOT/apps/teams"

sudo -u "$SITE_USER" -H env \
  XDG_CACHE_HOME="$CACHE_ROOT" COREPACK_HOME="$CACHE_ROOT/corepack" PNPM_HOME="$CACHE_ROOT/pnpm" \
  pnpm install --frozen-lockfile
sudo -u "$SITE_USER" -H env \
  XDG_CACHE_HOME="$CACHE_ROOT" COREPACK_HOME="$CACHE_ROOT/corepack" PNPM_HOME="$CACHE_ROOT/pnpm" \
  pnpm --filter api build
sudo -u "$SITE_USER" -H env \
  XDG_CACHE_HOME="$CACHE_ROOT" COREPACK_HOME="$CACHE_ROOT/corepack" PNPM_HOME="$CACHE_ROOT/pnpm" \
  pnpm --filter teams build

supervisorctl start gameday-api gameday-teams
sleep 8
supervisorctl status gameday-api gameday-teams
No database migration is included in this package. Rollback affects application files and dependencies only.
