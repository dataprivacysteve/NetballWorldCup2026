Do not deploy origin/main.The approved hotfix is the approved tag federation-hotfix-2026-09-15-r3, built from production commit b6d131cc83b0e8481512391d462d67bebf6f8ad5.
Do not paste commands from WhatsApp-rendered HTML.Use this file directly. Entities such as &#x20; and escaped underscores corrupt commands. Every STOP block below includes a visible STOP message and returns control to the prompt. Do not continue to the next numbered block after a STOP message.

Step 2 · Read-only preflight

Prove the exact starting point

PuTTY-safe modeRun one numbered code block at a time. The first three commands explicitly disable strict shell exit settings that may still be active from the earlier guide. 
set +e
set +u
set +o pipefail
echo "PASS: automatic shell exit is disabled"

export SITE_USER=web6
export SITE_GROUP=client0
export SOURCE_ROOT=/var/www/clients/client0/web6/web/gameday/source
export CACHE_ROOT=/var/www/clients/client0/web6/web/gameday/.cache
export BACKUP_ROOT=/var/backups/gameday
export REQUIRED_BASE=b6d131cc83b0e8481512391d462d67bebf6f8ad5
export APPROVED_REF=refs/tags/federation-hotfix-2026-09-15-r3
export RELEASE_TIME="$(date +%Y%m%d-%H%M%S)"
export EVIDENCE_ROOT="$BACKUP_ROOT/federation-hotfix-$RELEASE_TIME"

cd "$SOURCE_ROOT"
git diff --quiet && git diff --cached --quiet \
  || echo "STOP: tracked production changes exist — return to the prompt"
git fetch --prune --tags origin

export OLD_COMMIT="$(git rev-parse HEAD)"
export TARGET_COMMIT="$(git rev-list -n 1 "$APPROVED_REF")"
echo "OLD_COMMIT=$OLD_COMMIT"
echo "TARGET_COMMIT=$TARGET_COMMIT"

test "$OLD_COMMIT" = "$REQUIRED_BASE" \
  && echo "PASS: exact production base" \
  || echo "STOP: production is not on b6d131c — do not continue"

test -z "$(git diff --name-only "$REQUIRED_BASE" "$TARGET_COMMIT" -- apps/api/drizzle)" \
  && echo "PASS: hotfix contains no Drizzle migrations" \
  || echo "STOP: a Drizzle migration entered the hotfix — do not continue"

supervisorctl status gameday-api gameday-teams gameday-platform
ss -lntp | grep -E ':3000|:3002|:3003'
df -h "$SOURCE_ROOT" "$BACKUP_ROOT"
ExpectedExact base passes; no files under apps/api/drizzle differ; all three services are RUNNING; ports 3000, 3002 and 3003 are present.
